# Velero-UI

Velero-UI is part of the VUI project.

![alt text](/screenshots/velero-ui.gif)

[Read VUI project documentation](https://vui.seriohub.com/)

## Prerequisites

- **Node.js** 22+
- **pnpm** — This project uses [pnpm](https://pnpm.io/) as its package manager. Yarn and npm are not supported.

## Getting Started

```bash
pnpm install
pnpm dev
```

## Scripts

| Command                 | Description                                            |
| ----------------------- | ------------------------------------------------------ |
| `pnpm dev`              | Start development server (Turbopack)                   |
| `pnpm build`            | Production build                                       |
| `pnpm start`            | Start production server                                |
| `pnpm lint`             | Run ESLint                                             |
| `pnpm lint:fix`         | Run ESLint with auto-fix                               |
| `pnpm lint:cache`       | Run ESLint with caching                                |
| `pnpm format`           | Format code with Prettier                              |
| `pnpm format:check`     | Check code formatting with Prettier                    |
| `pnpm typecheck`        | Run TypeScript type checking                           |
| `pnpm test`             | Run all quality checks (format, lint, typecheck, jest) |
| `pnpm jest`             | Run Jest tests                                         |
| `pnpm jest:watch`       | Run Jest in watch mode                                 |
| `pnpm audit`            | Full security audit                                    |
| `pnpm audit:prod`       | Production-only security audit                         |
| `pnpm audit:signatures` | Verify package signatures                              |
